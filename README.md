# Indian-Railways-Performance-Punctuality

# Indian Railways Performance & Punctuality Analysis 🚆

This project analyzes **Indian Railways train performance and punctuality** using **Python, Pandas, NumPy, Matplotlib, Seaborn, and Power BI**.

The objective is to explore train and station-level performance, understand delays, analyze punctuality patterns, and identify areas where railway services can be improved.

## 🔍 Project Overview

The dataset contains **1,900 records** with information such as train number, train name, station code, station name, average delay in minutes, percentage of trains arriving on time, slight delays, significant delays, and cancelled/unknown records.

### 🛠️ Tools & Technologies

* **Python**
* **Pandas** – Data manipulation and cleaning
* **NumPy** – Numerical analysis
* **Matplotlib & Seaborn** – Data visualization
* **SciPy** – Statistical analysis
* **Power BI** – Interactive dashboard and business intelligence

### 🧹 Data Cleaning & EDA

The project includes:

* Dataset exploration and understanding
* Data type and statistical analysis
* Duplicate record checking
* Identification and removal of redundant columns
* Missing-value analysis
* Missing-value percentage calculation
* Missing-value heatmap
* Exploratory data analysis and visualizations

The analysis identified **236 missing values in the average delay column**, representing approximately **12.42% of the dataset**.

## 📊 Power BI Dashboard

An interactive **Power BI dashboard** was also created to present the analysis in a more visual and user-friendly way.

The dashboard helps users explore:

* 🚆 Train performance
* ⏱️ Average delay
* ✅ On-time performance
* 📍 Station-wise performance
* 📉 Delay patterns
* ❌ Cancellation/unknown percentages
* 🔎 Interactive filtering and comparisons
